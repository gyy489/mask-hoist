新版逻辑
只有头盔摄像头。
程序启动后默认 ESP32 控制 DISABLED，只检测、显示人框、显示当前命令，不向 ESP32 输出上下移动命令。
按空格切换 ESP32 控制 ENABLED / DISABLED。切到 DISABLED 时会先发送 STOP。
检测到人 = 当前命令 DOWN，让电葫芦收缩（当前现场开关接反，软件已反向）；只有 ESP32 ENABLED 时才真的输出。
检测不到人 = 当前命令 STOP，停止收缩；只有 ESP32 ENABLED 时才持续输出。
头盔摄像头拍到的内容可按需保存到 captures/helmet/<时间戳>/，默认关闭以减少卡顿。
Helmet View 默认最大化，按窗口高度自适应画面宽度，保持摄像头原始比例，不拉伸。
Helmet View 当前按 1280x960 / 4:3 使用，默认窗口也是 1280x960。
UI 叠字中，非中央信息使用 Swing 三栏自适应排版，等待文字默认 Helvetica Neue；中央 STOP/CONTRACT 大字保留在视频中心。
Helmet View 同一画面显示算法文字叠加层；主摄像头画面一直保留。无人时隐藏算法细节，保留顶部三栏每秒刷新状态信息和中央 STOP；检测到人时显示绿框。检测默认按 45 度步长扫描 8 个方向，摄像头斜着、横着、倒着都能触发。三栏信息区为每个检测框显示裁剪人像照片和对应算法细节。算法块和顶部状态使用同一套三栏布局，按窗口大小自适应。按 D 显示/隐藏。
自动识别发送 HOIST_CONTRACT_COMMAND，当前默认是 DOWN；只有按住 ↓ 的手动模式会发送 HOIST_DESCEND_COMMAND，当前默认是 UP。ESP32 DISABLED 时这些命令只显示，不写串口。
手动模式已加软件互锁：↑ 和 ↓ 同时按下时强制 STOP，不会输出 UP 或 DOWN；三个命令文本必须互不相同，避免配置绕开互锁。
不做电子高度闭环。
不做电子限位停止，依赖机器物理停止/限位。

树莓派
ssh ziyang@192.168.1.98
视频流: http://192.168.1.98:8080/stream
网页:   http://192.168.1.98:8080/
单帧:   http://192.168.1.98:8080/snapshot
服务:   mjpgcam.service
守护:   mjpgcam-guard.timer 每 20 秒检查 snapshot，失败则重启 mjpgcam
旧 RTSP 服务 rtspcam.service 当前停用，避免和网页流抢摄像头
旧 adaptive-stream.service 已停用，脚本里仍是 192.168.1.XX 的旧配置
当前稳定配置: uStreamer, 1280x960 MJPEG, 目标 30fps, --buffers 8 --workers 1, 摄像头端和客户端实测约 30fps
当前正常画面比例: 1280x960 = 4:3
硬件上报规格已记录在 README: MJPG 支持 1920x1080/1280x960/1280x720/1024x768/800x600/640x480/352x288/320x240/160x120/2592x1944/2048x1536；YUYV 支持 640x480/1280x720/2048x1536/1920x1080/1280x960/960x540/800x600/2592x1944
原因记录: 旧 uStreamer 默认只申请 2 个 V4L2 缓冲；1080p 推流时缓冲太紧，会触发 UVC 采集错误和 USB 摄像头重连。增加缓冲后，1080p 正式服务连续拉流通过且无新 USB/UVC 内核错误
测试记录: 2592x1944 可出图但 60 秒拉流中会 USB 断开；1920x1080 + 2 buffers 在 120 秒拉流中会 USB 断开；1920x1080 + 4 buffers 通过 180 秒连续拉流；1920x1080 + 8 buffers 通过 60 秒短测
4:3 测试记录: 2048x1536 摄像头端可 30fps 捕获、60 秒 HTTP 不断，但客户端 fps 一度约 17 且 SSH 曾短暂超时，不建议表演使用；1280x960 60 秒 HTTP 稳定，摄像头端和客户端均约 30fps，推荐作为 4:3 稳定档
排查记录: 2026-06-28 曾出现 USB 摄像头重连后只以 12M full-speed 枚举，导致只剩 160x120 YUYV 10fps；软件 unbind/bind 未恢复，重启树莓派后恢复 480M high-speed 和 1920x1080 MJPEG
卡顿排查: 2026-06-28 Helmet View 卡顿时，树莓派 mjpgcam 日志出现 Mainloop select() error / USB disconnect / Failed to set UVC probe control -71，本地 Java 进程也一度约 260% CPU。已把检测缩小到 640 宽、OpenCV 限 2 线程、UI 刷新限 20fps 并丢弃过期帧。如果仍卡，先查 /state 和 dmesg；USB 仍断就需要降推流 fps 或处理供电/线材。


按键
F 开关头盔画面上下翻转
D 显示/隐藏 Helmet View 上的算法文字叠加层
空格 启用/禁用 ESP32 控制；禁用时只检测和显示，不输出上下移动命令
↑ 手动上升/收缩，当前命令 HOIST_CONTRACT_COMMAND，默认 DOWN
↓ 手动下降/放松，当前命令 HOIST_DESCEND_COMMAND，默认 UP
ESC 发送 STOP 并退出
